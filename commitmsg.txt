Add URL routing, new-tab chart, fit-to-scale chart, and fix the AI slop

Syncs the local working copy (which was ahead of the repo) and implements the
four planned changes.

Chart
- The 50/200 DMA are computed on the full history before the timeframe is
  sliced, so they are correct from the first visible bar instead of ramping up
  from the left edge.
- The price axis is fitted to the selected timeframe (plus any reference lines),
  so a 1M view is not squashed by a multi-year range.

URLs and auth
- Real pages: /, /dashboard, /cycles, /excel, /alerts, /chart/{symbol}. Every
  page except / carries a guard that redirects to / before the page is built.
- "Open in new tab" on the stock detail view links to /chart/{symbol}.
- Login survives reloads and new tabs through an httponly cookie. The server
  stores only a SHA-256 hash of the token; signing out deletes the row.
- Deletes are scoped to the owner in the same SQL statement, so a guessed id
  cannot remove another account's data. Reads were already scoped.
- Demo login is off unless ENABLE_DEMO_LOGIN=1. The demo account has no known
  password (created with a random one that is never stored) and the username is
  reserved. render.yaml sets the flag so the button shows on Render.

AI slop removed, design and simplicity kept
- The institutional-cycle-intelligence badge, "Master Recurring", "Benchmark
  reference highs with precision", "100% Offline & Private", the emoji badges
  and the bullet separators are replaced with plain statements of what the app
  does.
- "Institutional Analytical Export" becomes "Analytical Export".

Tests: 34 -> 48. New coverage for session hashing, expiry, revocation, deleted
users, ownership-scoped deletes, and the demo flag.
