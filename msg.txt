Fix the reload loop: resolve session state in __init__, not build()

build() assigned to self.active_page, which marks the component dirty and
schedules another build — an infinite reload loop. Rio's observable properties
also raise AttributeError until assigned, so a field that was never set crashed
the first build.

- Move the session restore and the URL's requested page into __init__, which
  runs once before the first build.
- Assign every field explicitly, reading through a safe getter, so no property
  is left unset.
- build() now only reads state.

Verified: / returns 200, every protected route returns 307 to /, 48 tests pass.
